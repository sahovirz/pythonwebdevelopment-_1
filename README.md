# PixelBoard — Figma Style Web App

This is my very first Python web development project: a browser-based, Figma-inspired design playground.

## Features

- Dark design-tool interface with top toolbar, page/layer sidebar, canvas, and properties inspector.
- Interactive selection state shared between the canvas, layers list, and inspector.
- Insert your own frames, rectangles, ellipses, custom shapes, text blocks, and comments from the sidebar or toolbar.
- Click the canvas to place the active insert tool exactly where you want it.
- Apply gradient presets like Aurora, Sunset, Ocean, Candy, and Midnight to selected elements.
- Resize selected layers directly on the canvas with corner resize handles.
- Change layer shapes with rectangle, rounded, pill, circle, diamond, and triangle shaping controls or the on-canvas shape handle.
- Delete selected layers with the inspector button or the Delete/Backspace key.
- Draggable canvas objects for quick layout experiments.
- Editable layer metadata, position, size, fill color, corner radius, text, and comment copy.
- Add new rectangle layers with the sidebar + button or <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>D</kbd>.
- Responsive layout for smaller screens.

## Run locally

```bash
python app.py
```

Then open <http://localhost:8000> in your browser.
